I built this volume mixer to more easily control how loud different applications are on my PC. It's useful to be able to independently adjust volume of, for example, music, voice chat, and a video game. The CAD and manufacturing is all custom. The software is a fork of the open-source [deej](https://github.com/omriharel/deej) project. It uses a USB-C Arduino Micro and communicates using COM over USB.
